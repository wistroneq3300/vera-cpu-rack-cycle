OverviewOverview

本文件定義 Vera Cycle Validation Framework 已實作的共通驗證方法、判定語意與證據契約。它是 project-independent 的正式 validation specification，不是某一次 campaign 的結果，也不包含任何 project hardware expected quantity。This document defines the shared validation methods, result semantics, and evidence contracts implemented by the Vera Cycle Validation Framework. It is a project-independent validation specification, not a campaign result, and contains no project hardware expected quantities.

文件用途Document purpose

讓 reviewer 不需閱讀 Python 或 shell source，即可回答 PRE 做什麼、Cycle 如何確認完成、POST 如何比較，以及什麼情況會被判定為 PASS、WARN 或 FAIL。Enable a reviewer to understand PRE checks, cycle completion, POST comparison, and PASS/WARN/FAIL criteria without reading Python or shell source.
